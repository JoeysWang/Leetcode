## 1. 数组遍历

线性结构最常见的访问方式。用下标 `i` 从 0 走到 `length-1`，逐个取值。是所有数组题的基础——很多双指针/滑动窗口本质上就是在此基础上加约束地遍历。

```java
public void traverseArray(int[] nums) {
    for (int i = 0; i < nums.length; i++) {
        int value = nums[i];
        System.out.println("index=" + i + ", value=" + value);
    }
}
```

## 2. 链表遍历

每次通过 next 指针走到下一个节点。链表没有下标，只能顺序走，所以"双指针"在链表上格外好用（快慢指针、前后指针）。

```java
public void traverseList(ListNode head) {
    for (ListNode cur = head; cur != null; cur = cur.next) {
        System.out.println(cur.val);
    }
}
```

## 3. 二叉树遍历

前序位置适合自顶向下，后序位置适合自底向上。一棵树的遍历框架只有这一个，几乎所有树题都是在这个框架的"前序/中序/后序"某个位置加逻辑。

```java
public void traverseTree(TreeNode root) {
    if (root == null) {
        return;
    }
    System.out.println("pre order: " + root.val);
    traverseTree(root.left);
    System.out.println("in order: " + root.val);
    traverseTree(root.right);
    System.out.println("post order: " + root.val);
}
```

## 4. 图遍历

graph[i] 表示节点 i 能到达的所有邻居。图比树多一个难点：可能有环，所以必须配一个 `visited` 数组防止死循环。另外图可能不连通，所以要外层套一个循环，对每个没访问过的节点都启动一次 DFS。

```java
public void traverseGraph(int[][] graph) {
    boolean[] visited = new boolean[graph.length];
    for (int i = 0; i < graph.length; i++) {
        dfsGraph(graph, i, visited);
    }
}

private void dfsGraph(int[][] graph, int node, boolean[] visited) {
    if (visited[node]) {
        return;
    }
    visited[node] = true;
    System.out.println("visit node: " + node);
    for (int next : graph[node]) {
        dfsGraph(graph, next, visited);
    }
}
```

## 5. DFS 模板

深度优先，一条路走到底，再回退走别的路。核心就两步：①进节点立刻标记 visited；②遍历所有未访问邻居。标记时机要在"入队/入栈时"而不是"出队时"，否则同一节点会被重复放进栈里。

```java
public void dfsTemplate(int[][] graph, int start) {
    boolean[] visited = new boolean[graph.length];
    dfsTemplate(graph, start, visited);
}

private void dfsTemplate(int[][] graph, int node, boolean[] visited) {
    // 这个点来过了，直接返回，避免环导致无限递归。
    if (visited[node]) {
        return;
    }
    // 第一次来到这个点，立刻标记。
    visited[node] = true;
    System.out.println("DFS visit node: " + node);
    // graph[node] 是 node 的邻居列表。
    for (int next : graph[node]) {
        dfsTemplate(graph, next, visited);
    }
}
```

## 6. BFS 模板

广度优先，先访问离 start 最近的一层，再访问下一层。天然适合求"最短步数/最短路径"（无权图）。用队列实现，关键细节是**入队时就标记 visited**，否则同一节点会被多次入队。

```java
public void bfsTemplate(int[][] graph, int start) {
    boolean[] visited = new boolean[graph.length];
    Queue<Integer> queue = new ArrayDeque<>();
    // BFS 推荐入队时就标记，避免同一个点被重复放进队列。
    queue.offer(start);
    visited[start] = true;

    while (!queue.isEmpty()) {
        int node = queue.poll();
        System.out.println("BFS visit node: " + node);
        for (int next : graph[node]) {
            if (visited[next]) {
                continue;
            }
            visited[next] = true;
            queue.offer(next);
        }
    }
}
```

## 7. 322. 零钱兑换

**完全背包 DP**。给你硬币面额数组 `coins` 和总金额 `amount`，求凑出该金额的最少硬币数。

- 状态：`dp[money]` = 凑出金额 `money` 所需的最少硬币数
- 转移：`dp[money] = min(dp[money], dp[money - coin] + 1)`，枚举每种硬币
- 初始化：`dp[0]=0`（金额 0 不需要硬币），其余设为 `amount+1` 当作"正无穷"哨兵（因为最多用 amount 个 1 元硬币，amount+1 即代表不可达）
- 答案：`dp[amount]`，若仍为哨兵则返回 -1

```java
public int coinChange(int[] coins, int amount) {
    int impossible = amount + 1;
    int[] dp = new int[amount + 1];
    Arrays.fill(dp, impossible);
    dp[0] = 0;

    for (int money = 1; money <= amount; money++) {
        for (int coin : coins) {
            if (money >= coin) {
                dp[money] = Math.min(dp[money], dp[money - coin] + 1);
            }
        }
    }
    return dp[amount] == impossible ? -1 : dp[amount];
}
```

## 8. 70. 爬楼梯

**一维 DP**，本质就是斐波那契。n 阶楼梯每次走 1 或 2 阶，问走到顶有多少种走法。

- 状态：`dp[i]` = 到达第 i 阶的方法数
- 转移：`dp[i] = dp[i-1] + dp[i-2]`（最后一步要么从 i-1 走来，要么从 i-2 走来）
- 因为只依赖前两项，可用两个滚动变量压缩到 O(1) 空间

```java
public int climbStairs(int n) {
    if (n <= 2) {
        return n;
    }
    int prev2 = 1;
    int prev1 = 2;
    for (int i = 3; i <= n; i++) {
        int cur = prev1 + prev2;
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}
```

## 9. 46. 全排列

**回溯**。给一个无重复数组，返回所有排列。回溯三件套：做选择 → 递归 → 撤销选择。这里用 `used` 数组标记某元素是否已在路径中，避免重复使用。

```java
public List<List<Integer>> permute(int[] nums) {
    List<List<Integer>> ans = new ArrayList<>();
    boolean[] used = new boolean[nums.length];
    backtrackPermute(nums, used, new ArrayList<>(), ans);
    return ans;
}

private void backtrackPermute(int[] nums, boolean[] used, List<Integer> path, List<List<Integer>> ans) {
    if (path.size() == nums.length) {
        ans.add(new ArrayList<>(path));
        return;
    }
    for (int i = 0; i < nums.length; i++) {
        if (used[i]) {
            continue;
        }
        used[i] = true;
        path.add(nums[i]);
        backtrackPermute(nums, used, path, ans);
        path.remove(path.size() - 1);
        used[i] = false;
    }
}
```

## 10. 77. 组合

**回溯**。从 1..n 中选 k 个数的所有组合。和全排列的区别：组合不分顺序，所以用 `start` 控制只往后选，避免出现 `[1,2]` 和 `[2,1]` 这种重复。

```java
public List<List<Integer>> combine(int n, int k) {
    List<List<Integer>> ans = new ArrayList<>();
    backtrackCombine(1, n, k, new ArrayList<>(), ans);
    return ans;
}

private void backtrackCombine(int start, int n, int k, List<Integer> path, List<List<Integer>> ans) {
    if (path.size() == k) {
        ans.add(new ArrayList<>(path));
        return;
    }
    for (int num = start; num <= n; num++) {
        path.add(num);
        backtrackCombine(num + 1, n, k, path, ans);
        path.remove(path.size() - 1);
    }
}
```

## 11. 78. 子集

**回溯**。返回数组的所有子集。和组合题的区别：子集长度任意，所以**每个节点都要收集一次答案**（不止叶子）。同样用 `start` 保证不重复。

```java
public List<List<Integer>> subsets(int[] nums) {
    List<List<Integer>> ans = new ArrayList<>();
    backtrackSubsets(nums, 0, new ArrayList<>(), ans);
    return ans;
}

private void backtrackSubsets(int[] nums, int start, List<Integer> path, List<List<Integer>> ans) {
    ans.add(new ArrayList<>(path));
    for (int i = start; i < nums.length; i++) {
        path.add(nums[i]);
        backtrackSubsets(nums, i + 1, path, ans);
        path.remove(path.size() - 1);
    }
}
```

## 12. 704. 二分查找

**经典二分（左闭右闭区间）**。在有序数组里找 target 下标。循环条件 `left <= right`，缩边界用 `mid±1`。找精确匹配时这是最稳妥的写法。

```java
public int binarySearch(int[] nums, int target) {
    int left = 0;
    int right = nums.length - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] == target) {
            return mid;
        } else if (nums[mid] < target) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return -1;
}
```

## 13. 34. 左边界

**二分求第一个 >= target 的位置（左闭右开区间）**。循环条件 `left < right`，`nums[mid] >= target` 时把 `right = mid` 向左压。结束时 `left` 即第一个 >= target 的下标，再判断是否等于 target。

```java
public int leftBound(int[] nums, int target) {
    int left = 0;
    int right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] >= target) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left < nums.length && nums[left] == target ? left : -1;
}
```

## 14. 34. 右边界

**二分求最后一个 <= target 的位置（左闭右开区间）**。`nums[mid] <= target` 时把 `left = mid + 1` 向右压。结束时 `left-1` 即最后一个 <= target 的下标，再判断是否等于 target。

```java
public int rightBound(int[] nums, int target) {
    int left = 0;
    int right = nums.length;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (nums[mid] <= target) {
            left = mid + 1;
        } else {
            right = mid;
        }
    }
    int index = left - 1;
    return index >= 0 && nums[index] == target ? index : -1;
}
```

## 15. 滑动窗口模板

**通用滑动窗口框架**。`right` 扩张窗口、`left` 收缩窗口，窗口内用 `window`/`need`/`valid` 三件套维护状态。换题只改两处：①"何时收缩"的条件；②"何时更新答案"的位置。下方注释给出了三种常见收缩条件。

```java
public void slidingWindowTemplate(String s, String t) {
    // need：题目要求窗口里必须包含哪些字符，以及每个字符需要几个。
    Map<Character, Integer> need = new HashMap<>();
    // window：当前窗口 [left, right) 里面已经有哪些字符。
    Map<Character, Integer> window = new HashMap<>();

    for (char c : t.toCharArray()) {
        need.put(c, need.getOrDefault(c, 0) + 1);
    }

    int left = 0;
    int right = 0;
    // valid：有多少种字符已经满足 need 的要求。
    int valid = 0;
    int bestStart = 0;
    int bestLen = Integer.MAX_VALUE;
    int maxLen = 0;

    while (right < s.length()) {
        char c = s.charAt(right);
        right++;

        if (need.containsKey(c)) {
            window.put(c, window.getOrDefault(c, 0) + 1);
            if (window.get(c).equals(need.get(c))) {
                valid++;
            }
        }

        while (windowNeedsShrink(need, window, valid)) {
            // 更新答案位置：窗口满足条件，并且即将收缩之前。
            if (right - left < bestLen) {
                bestStart = left;
                bestLen = right - left;
            }

            char d = s.charAt(left);
            left++;

            if (need.containsKey(d)) {
                if (window.get(d).equals(need.get(d))) {
                    valid--;
                }
                window.put(d, window.get(d) - 1);
            }
        }

        maxLen = Math.max(maxLen, right - left);
    }
}

// 收缩条件按题目改：
// 最小覆盖子串：valid == need.size()
// 最长无重复子串：window.get(c) > 1
// 固定长度异位词：right - left >= t.length()
private boolean windowNeedsShrink(Map<Character, Integer> need, Map<Character, Integer> window, int valid) {
    return valid == need.size();
}
```

## 16. 76. 最小覆盖子串

**滑动窗口求最短满足条件的子串**。给你字符串 s 和 t，找 s 中包含 t 所有字符的最短子串。收缩条件是 `valid == need.size()`（窗口已包含 t 的所有字符），在收缩过程中不断更新最短长度。

```java
public String minWindow(String s, String t) {
    Map<Character, Integer> need = new HashMap<>();
    Map<Character, Integer> window = new HashMap<>();
    for (char c : t.toCharArray()) {
        need.put(c, need.getOrDefault(c, 0) + 1);
    }

    int left = 0;
    int valid = 0;
    int start = 0;
    int minLen = Integer.MAX_VALUE;
    for (int right = 0; right < s.length(); right++) {
        char in = s.charAt(right);
        if (need.containsKey(in)) {
            window.put(in, window.getOrDefault(in, 0) + 1);
            if (window.get(in).equals(need.get(in))) {
                valid++;
            }
        }

        while (valid == need.size()) {
            if (right - left + 1 < minLen) {
                start = left;
                minLen = right - left + 1;
            }
            char out = s.charAt(left);
            left++;
            if (need.containsKey(out)) {
                if (window.get(out).equals(need.get(out))) {
                    valid--;
                }
                window.put(out, window.get(out) - 1);
            }
        }
    }
    return minLen == Integer.MAX_VALUE ? "" : s.substring(start, start + minLen);
}
```

## 17. 3. 无重复字符的最长子串

**滑动窗口求最长无重复子串**。收缩条件是 `count.get(in) > 1`（刚加入的字符在窗口里重复了），收缩到不重复为止，过程中记录最长长度。和 76 互为镜像：76 求最短满足，3 求最长满足。

```java
public int lengthOfLongestSubstring(String s) {
    Map<Character, Integer> count = new HashMap<>();
    int left = 0;
    int ans = 0;
    for (int right = 0; right < s.length(); right++) {
        char in = s.charAt(right);
        count.put(in, count.getOrDefault(in, 0) + 1);
        while (count.get(in) > 1) {
            char out = s.charAt(left++);
            count.put(out, count.get(out) - 1);
        }
        ans = Math.max(ans, right - left + 1);
    }
    return ans;
}
```

## 18. 141. 环形链表

**快慢指针判环**。快指针每次走两步、慢指针每次走一步，若有环必相遇（快套慢一圈）；若无环，快指针先到 null。空间 O(1)，比哈希表法更优。

```java
public boolean hasCycle(ListNode head) {
    ListNode slow = head;
    ListNode fast = head;
    while (fast != null && fast.next != null) {
        slow = slow.next;
        fast = fast.next.next;
        if (slow == fast) {
            return true;
        }
    }
    return false;
}
```

## 19. 167. 两数之和 II

**有序数组双指针**。数组已升序，用左右指针：和小了左指针右移，和大了右指针左移。O(n) 时间 O(1) 空间，比哈希表法更适合有序输入。返回的下标从 1 开始（题目要求）。

```java
public int[] twoSumSorted(int[] numbers, int target) {
    int left = 0;
    int right = numbers.length - 1;
    while (left < right) {
        int sum = numbers[left] + numbers[right];
        if (sum == target) {
            return new int[]{left + 1, right + 1};
        } else if (sum < target) {
            left++;
        } else {
            right--;
        }
    }
    return new int[]{-1, -1};
}
```

## 20. 111. 二叉树的最小深度

**BFS 层序遍历求最短深度**。最小深度 = 根到最近叶子的节点数。用 BFS 逐层走，遇到第一个叶子立刻返回当前 depth——不必遍历整棵树，这是 BFS 求最短路径的优势。注意单子树时不能把另一侧 null 当叶子。

```java
public int minDepth(TreeNode root) {
    if (root == null) {
        return 0;
    }
    Queue<TreeNode> queue = new LinkedList<>();
    queue.offer(root);
    int depth = 1;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            TreeNode node = queue.poll();
            if (node.left == null && node.right == null) {
                return depth;
            }
            if (node.left != null) {
                queue.offer(node.left);
            }
            if (node.right != null) {
                queue.offer(node.right);
            }
        }
        depth++;
    }
    return depth;
}
```

## 21. 752. 打开转盘锁

**BFS 求无权图最短步数**。从 "0000" 拨到 target，每位可上拨/下拨，避开 deadends。每个状态有 8 个邻居（4 位 × 2 方向）。技巧：`visited.add(next)` 返回值同时完成"判重 + 标记"，一步顶两步。

```java
public int openLock(String[] deadends, String target) {
    Set<String> dead = new HashSet<>(Arrays.asList(deadends));
    if (dead.contains("0000")) {
        return -1;
    }

    Queue<String> queue = new ArrayDeque<>();
    Set<String> visited = new HashSet<>();
    queue.offer("0000");
    visited.add("0000");

    int steps = 0;
    while (!queue.isEmpty()) {
        int size = queue.size();
        for (int i = 0; i < size; i++) {
            String cur = queue.poll();
            if (cur.equals(target)) {
                return steps;
            }
            for (String next : lockNeighbors(cur)) {
                if (!dead.contains(next) && visited.add(next)) {
                    queue.offer(next);
                }
            }
        }
        steps++;
    }
    return -1;
}

private List<String> lockNeighbors(String cur) {
    List<String> ans = new ArrayList<>();
    char[] chars = cur.toCharArray();
    for (int i = 0; i < chars.length; i++) {
        char old = chars[i];
        chars[i] = old == '9' ? '0' : (char) (old + 1);
        ans.add(new String(chars));
        chars[i] = old == '0' ? '9' : (char) (old - 1);
        ans.add(new String(chars));
        chars[i] = old;
    }
    return ans;
}
```

## 22. 10. 正则表达式匹配

**二维 DP**。支持 `.`（匹配任意单字符）和 `*`（前一个字符匹配 0 次或多次）。`dp[i][j]` 表示 s 前 i 个字符能否被 p 前 j 个字符匹配。

- 若 `p[j-1] == '*'`：可"匹配 0 次"（`dp[i][j-2]`，删掉"前字符+*"）或"匹配多次"（当 `p[j-2]` 能匹配 `s[i-1]` 时取 `dp[i-1][j]`）
- 否则：当前字符相等或 p 是 `.`，则 `dp[i][j] = dp[i-1][j-1]`
- 初始化：`dp[0][0]=true`（空串匹配空模式）；还要处理 `s="" p="a*"` 这种空串能匹配的情况

```java
public boolean regexMatch(String s, String p) {
    int m = s.length();
    int n = p.length();
    boolean[][] dp = new boolean[m + 1][n + 1];
    dp[0][0] = true;

    for (int j = 2; j <= n; j++) {
        if (p.charAt(j - 1) == '*') {
            dp[0][j] = dp[0][j - 2];
        }
    }

    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            char pc = p.charAt(j - 1);
            if (pc == '*') {
                dp[i][j] = dp[i][j - 2];
                char prev = p.charAt(j - 2);
                if (prev == '.' || prev == s.charAt(i - 1)) {
                    dp[i][j] = dp[i][j] || dp[i - 1][j];
                }
            } else if (pc == '.' || pc == s.charAt(i - 1)) {
                dp[i][j] = dp[i - 1][j - 1];
            }
        }
    }
    return dp[m][n];
}
```
